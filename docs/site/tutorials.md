# Tutorials

Work through these examples after the [Quick Start](quickstart.md).

- [Multi-basin calibration](multi-basin.md): independent catchment fits or a shared parameter vector, with process-level parallelism.
- [Examples and reports](examples.md): observed records, reproducible scripts, hydrographs, multi-start fitting and parameter-scenario ensembles.

Parameter-scenario ensembles describe the supplied scenarios. They are not posterior uncertainty estimates or a substitute for sensitivity analysis.
