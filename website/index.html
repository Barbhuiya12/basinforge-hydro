01 / A REPEATABLE EXPERIMENT

Fit once. Understand what happened.

01

Prepare your basin

Provide continuous precipitation, PET and observed discharge. Units and daily, monthly or annual frequency are checked explicitly.

02

Calibrate without leakage

Choose independent or shared basin parameters. Train chronologically, exclude warmup, and select multi-start fits by training loss.

03

Inspect the holdout

Continue stores through validation. Save parameters, hydrographs, flow-duration plots, metrics and scenario spread.

03 / EVIDENCE, NOT JUST A DEMO

Actual observations. Honest results.

Five implementations on the same 3,287-day LuMod catchment record. First 70% training, remaining 30% validation; 365-day warmup and only 12 Latin-hypercube candidates.

Validation NSE

Higher is better. NSE = 0 matches the observed-mean baseline; negative values are worse. See the study for exact metric definitions.

Start with your own catchment.

TERMINAL / SOURCE INSTALL
git clone https://github.com/Barbhuiya12/basinforge-hydro.git
cd basinforge-hydro
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
basinforge models

macOS/Linux activation shown. Windows: .venv\Scripts\activate. Octave is installed separately. No account, API key or cloud service is needed to run the package.

05 / SCIENTIFIC BOUNDARIES

What we do—and do not—claim.

Identified implementations

LuMod, hydromodel and SMARTpy variants are labeled precisely. MARRMoT uses standardized structures and a documented compatibility patch.

Sources & licenses →

Transparent uncertainty

Parameter-scenario quantiles are descriptive, not posterior samples or predictive confidence intervals. Weighted objectives are scalarized, not Pareto optimization.
